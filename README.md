# Análisis de Control de Gastos del Hogar

Este proyecto ha sido desarrollado como parte de mi formación en **Ciencia de Datos**, aplicando técnicas de análisis exploratorio de datos (EDA) y manipulación de datos estructurados para optimizar la gestión financiera dentro de un entorno doméstico.

## 📁 Estructura del Proyecto

* **`Control_Gastos_Casa.csv`**: Conjunto de datos que contiene el registro histórico de los ingresos, egresos y categorías de gastos de la vivienda.
* **`Control_GC.ipynb`**: Cuaderno de Jupyter (Jupyter Notebook) con el código en Python utilizado para la limpieza, procesamiento y visualización de las métricas clave.

## 🛠️ Tecnologías Utilizadas

* **Python**
* **Pandas** (para la manipulación de datos)
* **Matplotlib / Seaborn** (para la visualización de gráficos estadísticos)

## 📈 Objetivos del Análisis

1. Identificar las categorías de mayor consumo mensual para proponer estrategias de ahorro.
2. Evaluar el comportamiento temporal de los gastos en comparación con el presupuesto asignado.
3. Detectar anomalías o variaciones atípicas en los egresos habituales.
